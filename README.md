# گزارش منتورینگ — آکادمی سبحان صمدی (نسخه ۲)

PWA کامل مدیریت منتورینگ: گزارش‌های هفتگی، آرشیو، مرخصی منتورها، پروژه‌ها و داشبورد آماری.
تمام داده‌ها به‌صورت محلی (localStorage) روی همان دستگاهی که برنامه نصب می‌شود ذخیره می‌گردد و هیچ گزارشی حذف نمی‌شود مگر با تأیید صریح مدیر.

## فایل‌های پروژه
- `index.html` — پوسته اصلی برنامه
- `app.js` — منطق کامل برنامه
- `data.js` — داده‌های اولیه (منتورها، رمزها، مقادیر پیش‌فرض)
- `manifest.json` / `sw.js` — پیکربندی PWA و حالت آفلاین
- `assets/` — لوگو، آیکون‌ها و تصویر پس‌زمینه

## ورود به برنامه
- **ورود عادی (مشاهده‌گر):** رمز پیش‌فرض `sobhan1404` — فقط مشاهده گزارش‌ها، آرشیو، مرخصی و پروژه‌ها.
- **پنل مدیریت (مخفی):** روی لوگوی صفحه ورود ۵ بار سریع ضربه بزنید (یا لمس طولانی نگه دارید) تا پنجره رمز مدیر باز شود. رمز پیش‌فرض `mentor1404`.
- هر دو رمز از داخل پنل مدیریت ← تنظیمات ← «تغییر رمزهای عبور» قابل تغییر هستند.

## مراحل نصب روی GitHub Pages (رایگان)

### مرحله ۱ — ساخت اکانت GitHub
1. برو به [github.com](https://github.com)
2. روی **Sign up** کلیک کن
3. ایمیل، پسورد، و نام کاربری بساز

### مرحله ۲ — ساخت Repository
1. بعد از لاگین، روی **+** (بالا راست) کلیک کن
2. **New repository** رو انتخاب کن
3. نام: `sobhan-report`
4. گزینه **Public** رو انتخاب کن
5. روی **Create repository** کلیک کن

### مرحله ۳ — آپلود فایل‌ها
1. در صفحه repository، روی **uploading an existing file** کلیک کن
2. تمام فایل‌ها و پوشه `assets` را drag & drop کن (ساختار پوشه‌ها باید حفظ شود)
3. روی **Commit changes** کلیک کن

### مرحله ۴ — فعال‌سازی GitHub Pages
1. در repository، روی **Settings** کلیک کن
2. از منوی چپ **Pages** رو انتخاب کن
3. در قسمت Source، **main branch** رو انتخاب کن
4. روی **Save** کلیک کن

### مرحله ۵ — آدرس اپ
بعد از چند دقیقه، اپت روی این آدرس در دسترسه:
`https://[نام-کاربری-گیتهاب].github.io/sobhan-report`

### نصب روی گوشی
1. آدرس رو در Chrome (اندروید) یا Safari (آیفون) باز کن
2. بنر «نصب اپ» رو می‌بینی — روش کلیک کن
3. یا: منوی مرورگر ← «Add to Home Screen» / «افزودن به صفحه اصلی»

پس از نصب، برنامه دقیقاً مانند یک اپ بومی (بدون نوار آدرس مرورگر) و حتی بدون اینترنت قابل اجراست.

## نکات فنی
- داده‌ها در `localStorage` مرورگر/اپ نصب‌شده ذخیره می‌شوند؛ برای پشتیبان‌گیری از منوی تنظیمات «خروجی JSON» بگیرید.
- برای تغییر نسخه کش آفلاین، مقدار `CACHE_NAME` در `sw.js` را افزایش دهید.
