# FitOS Personal

اپ اندرویدی شخصی برای بدنسازی، تغذیه، بدن و عادت‌ها. آفلاین، فارسی و راست‌به‌چپ، با تاریخ شمسی.

- شناسه اپ: `app.fitos.personal`
- حداقل اندروید: ۸ (API 26)، هدف: API 36
- بدون مجوز اینترنت. همه داده‌ها فقط روی گوشی می‌ماند.

## نصب روی گوشی

1. فایل `app-release.apk` را روی گوشی بیاورید.
2. روی فایل بزنید. اگر اندروید اجازه خواست، «نصب از این منبع» را برای همان برنامه (مثلاً مدیر فایل یا تلگرام) روشن کنید.
3. «نصب» را بزنید.

نسخه‌های بعدی را روی همین نسخه نصب کنید (حذف نکنید). چون همه نسخه‌ها با یک کلید امضا می‌شوند، اطلاعات حفظ می‌شود.
اگر اندروید گفت «امضای برنامه فرق دارد»، نسخه قبلی را حذف نکنید و اول از اطلاعات پشتیبان بگیرید (از مرحله ۲ به بعد).

## ساخت از سورس

پیش‌نیاز: JDK 17 یا جدیدتر، Android SDK (platform 36).

```bash
cd fitos-android
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew test lintDebug      # تست‌ها و بررسی کد
./gradlew assembleDebug       # نسخه آزمایشی: app/build/outputs/apk/debug/
./gradlew assembleRelease     # نسخه نهایی: app/build/outputs/apk/release/
```

نسخه نهایی فقط وقتی امضا می‌شود که `keystore.properties` کنار همین فایل باشد یا متغیرهای محیطی `FITOS_*` تنظیم شده باشند. جزئیات در [docs/SIGNING.md](docs/SIGNING.md).

در GitHub، هر تغییر در این پوشه با [workflow](../.github/workflows/fitos-android.yml) ساخته و تست می‌شود و APK در بخش Artifacts همان اجرا قرار می‌گیرد.

## ساختار

```
fitos-android/
├─ app/                  صفحه‌ها، ناوبری، ظرف وابستگی‌ها
├─ core/domain/          منطق خالص کاتلین: تقویم شمسی، اعداد فارسی، مدل‌ها و قواعد
├─ core/data/            ذخیره‌سازی: DataStore (و Room از مرحله ۱)
├─ core/designsystem/    سیستم طراحی: رنگ، فونت، شکل، آیکون، ایموجی، اجزای مشترک
├─ docs/                 معماری، امضا، سیستم طراحی (HTML)
└─ tools/                ابزار تولید آیکون‌ها از اسپرایت سیستم طراحی
```

معماری در [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) و سیستم طراحی در [docs/design-system/](docs/design-system/README.md).

## حریم خصوصی

- مجوز `INTERNET` در اپ وجود ندارد، پس هیچ داده‌ای نمی‌تواند از گوشی خارج شود.
- پشتیبان‌گیری خودکار گوگل و انتقال بین دستگاه‌ها خاموش است. پشتیبان فقط فایلی است که خودتان می‌سازید.
- هیچ داده آزمایشی یا ساختگی در اپ نیست. چیزی که ثبت نشده، «ثبت نشده» نشان داده می‌شود.
